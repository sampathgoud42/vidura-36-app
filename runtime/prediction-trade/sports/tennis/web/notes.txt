## Install & run
```bash
pip install playwright
playwright install chromium      # one-time browser download

python tennis/web/sofascore_rankings.py          # both ATP + WTA → tennis_rankings.csv
python tennis/web/sofascore_rankings.py atp       # one tour
SOFA_HEADLESS=FALSE python tennis/web/sofascore_rankings.py   # debug headful
```
For your daily Kalshi run, just schedule that command once a day (CSV is overwritten each run). Tunables via env: `SOFA_OUTPUT`, `SOFA_HEADLESS`, `SOFA_NAV_TIMEOUT_MS`, `SOFA_DATA_WAIT_S`, `SOFA_RETRIES`, `SOFA_UA`.
